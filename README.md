# kinsense-public

Public static hosting for the **KinSense** mobile app — currently the privacy policy.

- **Privacy policy:** [`index.html`](index.html) → served via GitHub Pages.

## Source of truth
The canonical policy text lives in the private app repo at `PRIVACY.md`. `index.html`
here is the rendered, public version. When the policy changes, update it there and
regenerate this page.

Placeholder values are filled in (developer **smart-apps**, contact
**yuvdror@gmail.com**, effective **July 26, 2026**, location-history retention **7 days**,
minimum age **4**). Still advisable to have the policy reviewed for your jurisdiction
(Israel + EEA/UK for GDPR, California for CCPA), and note the app does not yet enforce
the stated 7-day location-history pruning — add that job to honor it.
