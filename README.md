# kinsense-public

Public static hosting for the **KinSense** mobile app — currently the privacy policy.

- **Privacy policy:** [`index.html`](index.html) → served via GitHub Pages.

## Source of truth
The canonical policy text lives in the private app repo at `PRIVACY.md`. `index.html`
here is the rendered, public version. When the policy changes, update it there and
regenerate this page.

> **Before store submission:** fill in the remaining `[PLACEHOLDER]` values in
> `index.html` (effective date, company/name, contact email, retention period, minimum
> age) and have the policy reviewed for your jurisdiction.
